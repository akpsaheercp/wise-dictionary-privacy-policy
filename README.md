# Privacy Policy for Wise Dictionary

**Effective Date:** November 24, 2026  
**Application:** Wise Dictionary (`com.wise.dictionary`)

## 1. Introduction
This Privacy Policy applies to the mobile application **Wise Dictionary** (the "Application"), developed and maintained by **AKP Saheer**. This document outlines our principles regarding user data, permissions, and security.

## 2. Information Collection and Use
Wise Dictionary is designed to function primarily as an offline reference tool:
- **No Personal Data Collected:** We do not ask for, gather, track, or store any personal data such as your name, email address, phone number, physical address, contacts, photos, or location.
- **No Account Required:** You can use all features of the Application without creating an account or registering personal credentials.
- **No User Profiling or Analytics:** We do not track your searches, usage patterns, or device identifiers for marketing or behavioral advertising.

## 3. Local Device Storage
Any data generated while using the Application is stored solely on your local device:
- **Search History:** Saved locally in the Application's private database on your device to help you quickly re-access previous lookups.
- **Bookmarks & Favorites:** Stored locally on your device.
- **User Preferences:** Theme settings (Dark/Light mode), font sizes, and display preferences are stored locally via SharedPreferences.

None of this local data is transmitted to external servers, cloud storage, or third parties.

## 4. Device Permissions
The Application requests only standard network permissions strictly necessary for downloading dictionary datasets:
- `android.permission.INTERNET`: Required solely when downloading dictionary database packages (such as Al-Manhal or Al-Mawrid) or original book page images on demand.
- `android.permission.ACCESS_NETWORK_STATE` and `ACCESS_WIFI_STATE`: Used to verify network connectivity before starting a download to avoid unnecessary failures.

The Application **does not request** access to sensitive device features such as Camera, Microphone, Contacts, Location, SMS, or Phone State.

## 5. Third-Party Services and Content Delivery
To provide large offline dictionary files and source page images without bloating the base application download, the Application downloads resources over secure encrypted HTTPS connections from trusted hosting infrastructure (Hugging Face / GitHub).

We do not use third-party advertising SDKs (e.g., Google AdMob), analytics SDKs, or social media trackers.

## 6. Children's Privacy
Wise Dictionary does not address anyone under the age of 13. We do not knowingly collect personally identifiable information from children under 13. Since no personal data is collected from any user, children can safely use the Application for educational and reference purposes.

## 7. Security
We value your trust. All network transmissions for dictionary resource downloads are performed over secure HTTPS (TLS/SSL). Sensitive dictionary assets are stored securely within the Application's private internal storage directory.

## 8. Data Retention and Deletion
Because we do not store any user data on remote servers, we do not retain any personal data. You have full control over your local data:
- You can clear your search history and bookmarks directly inside the Application's settings.
- You can delete all application data and cache at any time via your device's **Settings → Apps → Wise Dictionary → Storage → Clear Data**, or by uninstalling the Application.

## 9. Changes to This Privacy Policy
We may update our Privacy Policy from time to time. Any changes will be posted on this webpage with an updated "Effective Date".
